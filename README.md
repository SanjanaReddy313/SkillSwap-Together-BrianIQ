# SkillSwap Together – BrainIQ

## Project Introduction
SkillSwap Together – BrainIQ is a skill-sharing
platform that connects people who want to learn
new skills with people who can teach them.

## Objectives
- Encourage knowledge sharing.
- Help users discover learning partners.
- Allow users to schedule learning sessions.
- Support communication between students and mentors.
- Collect ratings and feedback.

## Main Features
1. My Profile
2. My Skills
3. Find People
4. Connect
5. Book a Session
6. My Bookings
7. Chat
8. Notifications
9. Ratings and Feedback

- HTML
